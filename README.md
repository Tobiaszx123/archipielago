# Archipiélago

Juego de mesa de islas y hexágonos para el navegador: fundá pueblos, juntá recursos, comerciá y construí.

**Jugar:** https://tobiaszx123.github.io/archipielago/

- Contra bots con personalidad, o online con amigos (sin cuenta).
- Funciona en el celular (mejor en horizontal) y en la compu.
- Online: uno toca **Online → Crear sala → 📲 Invitar** y le manda el link a sus amigos. El celular de quien crea la sala lleva la partida y tiene que quedar con el juego abierto.
